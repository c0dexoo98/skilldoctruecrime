# True Crime Video Producer — Continuous World

A reusable Manus skill and starter kit for ethical, narration-led true-crime work. Its video mode builds a single continuous camera journey over one persistent world using deterministic code-rendered frames—never an AI video generator, stock footage, clips, cuts, or slide changes.

## Included

- `true-crime-video-producer/SKILL.md` — installable staged workflow with mandatory beat-table approval and continuous-world constraints.
- `true-crime-video-producer/references/continuous-world-code-rendering.md` — code-rendering architecture, camera path, text uniqueness, and QA implementation notes.
- `true-crime-video-producer/scripts/` and `templates/` — self-contained local intake utility, Python renderer, and editable project JSON bundled with the `.skill` install package.
- `docs/WORKFLOW.md` — operator workflow and approval gates.
- `docs/REFERENCE_STYLE.md` — single-world art direction and camera continuity.
- `docs/ETHICS_AND_FACT_CHECK.md` — sourcing, attribution, privacy, and factuality standards.
- `demo/storyboard.md` — asset-free example beat table; not a real case or ready-to-render project.
- `starter/intake.py` — local intake organizer; it makes no network requests.
- `starter/EDIT_PLAN_TEMPLATE.md` — beat table, camera path, text ledger, provenance and QA checklist.
- `starter/continuous-world/` — reusable deterministic code renderer template for a persistent world and configurable camera route.

The generic renderer is included both in the repository starter folder and inside the installable skill package. It has been smoke-tested with synthetic inputs only; it is a reusable starter, not a completed project film or a substitute for script/timing/beat-table approval.

## Install and use

Add `true-crime-video-producer/SKILL.md` in Manus (or use the `.skill` package). Begin with a request such as: “Plan a sourced 60-second true-crime short using my attached narration and approved photos, rendered as one continuous code-built world; show me the beat table before coding.”

The skill first records the exact format, script, measured narration, photo provenance/rights, and privacy limits. It then shows a timestamped table with one hero per narration line and asks for approval before building the world or rendering. If a new project says to forget prior assets, it will not reuse them. Missing audio/photos are requested, not silently replaced.

## Hard picture rules

- Every MP4 frame is generated by the code renderer.
- No AI video generator, stock footage, downloaded clips, cuts, scene swaps, or slide changes.
- Approved photos may be composited as physical prints/documents on the designed world; each source is recorded in the manifest.
- One world and one continuous smooth camera path persist from start to finish. The camera continues a slight drift during holds.
- Each spoken line has one hero. Show a phrase through only one screen channel (document, typeset overlay, or captions); never duplicate it.
- Keep props/text sparse, readable on a phone, and factually honest.

## Reusable intake

Run `python3 starter/intake.py` to create a local brief. This organizer does not upload or generate media. Use it to collect the new project inputs; do not place private narration, photos, credentials, or client data in the public repository.
